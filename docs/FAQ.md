# 常見問題與疑難排解

## 安裝與啟動

### Q1. 啟動時出現找不到 .NET 或 Windows App Runtime 的訊息？

本專案的 ZIP 為**非 Self-Contained（framework-dependent）**版本，請安裝：

1. [.NET 10 Runtime](https://dotnet.microsoft.com/download/dotnet/10.0)（x64 或 ARM64 對應版本）
2. [Windows App Runtime 1.8](https://learn.microsoft.com/windows/apps/windows-app-sdk/downloads)

安裝後重新啟動程式。

### Q2. SmartScreen 顯示「Windows 已保護您的電腦」？

目前發行檔未進行程式碼簽章。若確認檔案來自本專案的 GitHub Releases，可點選「更多資訊」→「仍要執行」。請勿執行來源不明的檔案。

### Q3. 應該下載 x64 還是 ARM64？

- Intel／AMD 處理器：x64
- Snapdragon X 等 Windows on ARM 裝置：ARM64

可於「設定」→「系統」→「關於」查看系統類型。

## 連線

### Q4. 找不到裝置？

1. 確認已安裝 Android Platform Tools，且 `adb devices` 可看到裝置。
2. 確認手機已開啟「USB 偵錯」。
3. 解鎖手機，並在「允許 USB 偵錯」對話框按允許。
4. 更換 USB 線或連接埠（部分線材僅供充電）。
5. 於程式「設定」頁確認 ADB 路徑正確。

### Q5. 裝置顯示「未授權」？

在手機上確認 USB 偵錯授權。若未跳出對話框：

1. 進入手機「開發者選項」→「撤銷 USB 偵錯授權」。
2. 重新插拔 USB。
3. 再次允許授權。
4. 某些品牌需同時開啟「USB 安裝」或關閉「MIUI 優化」。

### Q6. 無線配對失敗？

- 確認手機與電腦在同一區域網路。
- 確認使用的是「配對連接埠」，不是連線連接埠。
- 配對碼為 6 位數，且配對視窗需保持開啟。
- 防火牆需允許 ADB 與區域網路通訊。
- 若仍失敗，可先以 USB 連線後使用「切換為無線連線」。

### Q7. 「切換為無線連線」失敗？

- 確認手機已連上 Wi-Fi，且與電腦同網段。
- 部分路由器啟用「AP 隔離」會阻擋裝置互連。
- 確認 `adb tcpip 5555` 成功；某些裝置需重新插拔 USB。
- 可改用手動「無線連線」輸入 IP 與連接埠。

### Q8. 常用無線裝置重連失敗？

手機的無線偵錯連接埠可能已變更。請進入手機「無線偵錯」查看目前 IP 與連接埠，重新連線後會更新紀錄。

## 畫面

### Q9. 連線成功但畫面黑屏？

1. 確認手機螢幕已解鎖。
2. 於設定頁切換 H.264／H.265 測試。
3. 更新顯示卡驅動程式。
4. 查看日誌是否顯示解碼器初始化失敗。
5. 確認 `scrcpy-server` 版本與設定頁版本號一致（預設 5.0.1）。

### Q10. 畫面只顯示左上角或比例錯誤？

本專案已使用 `IDXGISwapChain2::SetMatrixTransform` 處理縮放。若仍發生：

- 嘗試調整視窗大小或使用「貼合比例」。
- 確認 Windows 顯示縮放（125%／150%／200%）設定後重新連線。
- 回報時請附上 Windows 版本、顯示卡型號與解析度。

### Q11. 畫面邊緣出現綠色條？

此問題與 H.264 巨集區塊補齊有關，程式已透過顯示區域（aperture）裁切處理。若仍出現，請更新至最新版本並回報裝置型號與解析度。

### Q12. 延遲很高或畫面卡頓？

- Wi-Fi 環境建議降低最大解析度、位元率或 FPS。
- 改用 USB 連線。
- 關閉其他佔用網路或 GPU 的程式。
- 確認效能 HUD 顯示為 DXVA GPU；若為 CPU，可能是硬解不支援。

### Q13. H.265 無法使用？

系統需安裝 HEVC 解碼器。程式偵測不到時會自動退回 H.264。可於 Microsoft Store 安裝「HEVC 影片延伸模組」，或改用 H.264。

## 輸入

### Q14. 鍵盤輸入沒有反應？

1. 先點擊同步畫面，讓鍵盤焦點位於畫面上。
2. 確認手機輸入法可接受文字注入。
3. 中文／Emoji 會透過剪貼簿貼上，請確認剪貼簿同步未被系統安全軟體阻擋。

### Q15. 中文輸入變成亂碼或沒有貼上？

- 非 ASCII 文字使用 `SET_CLIPBOARD(paste: true)`。
- 確認手機目前有可輸入文字的欄位取得焦點。
- 部分輸入法可能攔截貼上，請改用英文或直接以手機輸入。

### Q16. 滑鼠點擊位置不準？

- 使用「貼合比例」讓畫面與視窗比例一致。
- 避免在非整除縮放下操作微小元件。
- 若使用多螢幕不同 DPI，請回報設定以利修正。

### Q17. 拖曳中斷後手機觸控卡住？

程式會在 `PointerCanceled` 時補送 `Up` 事件。若仍發生，可點擊一次畫面或重新連線。

## 音訊

### Q18. 沒有聲音？

1. 確認設定頁「同步播放手機音訊」已開啟。
2. 確認 Android 版本為 11 以上。
3. 檢查 Windows 音量與預設輸出裝置。
4. 部分裝置限制音訊擷取，程式會自動以純畫面模式繼續。

### Q19. 聲音延遲或斷斷續續？

- 使用 AAC 壓縮音訊可降低 Wi-Fi 頻寬。
- 改用 USB 連線。
- 確認 WASAPI 路徑正常；若退回 WaveOut，延遲可能較高。
- 切換 Windows 預設音訊裝置後，WASAPI 會自動跟隨。

## 功能

### Q20. 截圖存到哪裡？

存至「圖片」資料夾下的 `AndroidSync` 子資料夾，檔名為 `AndroidSync_yyyyMMdd_HHmmss.png`，同時複製到剪貼簿。

### Q21. 拖放 APK 沒有安裝？

- 確認手機已允許「USB 安裝」。
- 確認 APK 檔案完整且未損毀。
- 部分品牌需在開發者選項額外開啟「透過 USB 安裝應用程式」。

### Q22. 關閉程式後 adb 仍佔用連接埠？

正常關閉時會移除轉發並結束 `scrcpy-server`。若程式異常終止，可手動執行：

```powershell
adb forward --remove-all
```

### Q23. 為什麼不能同時開兩個視窗？

程式採單一實例設計，再次啟動會將既有視窗帶回前景，避免同時建立多個 ADB 轉發與解碼器。

### Q24. 支援螢幕錄影嗎？

不支援。螢幕錄影已列為非目標。
