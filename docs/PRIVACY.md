# 隱私權說明

「Android同步」（以下稱本程式）重視使用者隱私。本文件說明本程式處理資料的方式。

## 1. 資料收集

本程式**不收集、不傳送、不出售**任何個人資料，也不包含遙測、分析或廣告 SDK。

## 2. 本機儲存

本程式僅在本機儲存以下設定：

- 位置：`%AppData%\AndroidSync\settings.json`
- 內容：
  - ADB 與 `scrcpy-server` 路徑
  - 視訊／音訊／剪貼簿等偏好設定
  - 曾連線的無線裝置 IP、連接埠與標籤
  - 視窗位置、大小與最大化狀態
  - 顯示模式與主題

上述資料不會離開你的電腦。你可隨時刪除該檔案以重設設定。

## 3. 網路連線

本程式的網路行為僅限於：

- 連線至本機 ADB 服務（`127.0.0.1:5037`）。
- 透過 ADB 轉發與 Android 裝置上的 `scrcpy-server` 通訊。
- 使用 Wi-Fi 時，與你指定的區域網路 Android 裝置通訊。

除上述用途外，本程式不會連線至任何第三方伺服器。

## 4. 剪貼簿

- 啟用雙向剪貼簿同步時，電腦與手機的剪貼簿內容會透過 ADB 通道傳輸。
- 傳輸僅發生在你的電腦與已連線的手機之間。
- 程式不會儲存或記錄剪貼簿內容。
- 你可於設定頁關閉此功能。

## 5. 檔案與 APK

- 僅在你主動拖放檔案時，才會將檔案推送至手機或安裝 APK。
- 程式不會自動下載、執行或上傳檔案。

## 6. 日誌

- 日誌僅用於除錯，可能包含路徑、裝置型號與錯誤訊息。
- 日誌不包含剪貼簿內容或檔案內容。
- 正式版不將日誌輸出至主控台；開發版輸出至 Visual Studio 輸出視窗。

## 7. 第三方元件

- `scrcpy-server` 於 Android 裝置上執行，其行為受該專案授權與隱私政策約束。
- `adb` 由使用者自行安裝，其行為受 Android SDK 條款約束。
- 詳見 [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md)。

## 8. 兒童隱私

本程式不收集任何使用者資料，亦不針對兒童設計資料收集機制。

## 9. 變更

若本政策有重大變更，將於專案儲存庫與發行說明中公告。
