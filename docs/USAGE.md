# 使用指南

本文件說明「Android同步」的安裝、連線、操作與設定方式。若遇到問題，請先參閱 [FAQ.md](FAQ.md)。

---

## 1. 安裝

### 1.1 下載發行版

至 [GitHub Releases](https://github.com/mark216tw/android-sync/releases) 下載符合系統架構的壓縮檔：

| 系統架構 | 檔案 |
| --- | --- |
| x64（Intel／AMD） | `AndroidSync-<版本>-win-x64-non-self-contained.zip` |
| ARM64（Snapdragon X 等） | `AndroidSync-<版本>-win-arm64-non-self-contained.zip` |

解壓縮至任意資料夾，例如 `C:\Apps\AndroidSync`。

> 這些是**非 Self-Contained（framework-dependent）**版本，需先安裝執行期元件。若希望免安裝 .NET 與 Windows App Runtime，請自行以 Self-Contained 方式發佈。

### 1.2 安裝執行期元件

1. **.NET 10 Runtime**（x64 或 ARM64 對應版本）
   - 下載：https://dotnet.microsoft.com/download/dotnet/10.0
2. **Windows App Runtime 1.8**
   - 下載：https://learn.microsoft.com/windows/apps/windows-app-sdk/downloads
   - 請選擇與應用程式版本相符的 **1.8** 執行期。

### 1.3 準備 ADB

本程式需要 `adb.exe`（Android SDK Platform Tools）。可透過以下任一方式提供：

1. 將 `adb.exe` 放在程式目錄下的 `Tools\adb.exe`。
2. 設定環境變數 `ANDROID_HOME` 或 `ANDROID_SDK_ROOT`，程式會尋找 `platform-tools\adb.exe`。
3. 安裝 Android SDK 至預設路徑 `%LOCALAPPDATA%\Android\Sdk\platform-tools\adb.exe`。
4. 將 `adb.exe` 所在資料夾加入系統 `PATH`。
5. 於程式「設定」頁的「ADB 路徑」欄位指定完整路徑。

> `scrcpy-server` 已內附於 `Tools\scrcpy-server`，通常不需要額外下載。

## 2. 準備 Android 手機

### 2.1 USB 有線連線

1. 進入手機「設定」→「關於手機」，連續點擊「版本號碼」7 次以開啟開發者選項。
2. 進入「開發者選項」，開啟 **USB 偵錯**。
3. 以 USB 線連接電腦。
4. 手機跳出「允許 USB 偵錯嗎？」時，勾選「一律允許」並按「允許」。
5. 部分品牌（小米、OPPO、vivo 等）還需開啟「USB 安裝」或關閉 MIUI 優化；若仍無法連線，請參閱 [FAQ.md](FAQ.md)。

### 2.2 Wi-Fi 無線連線（Android 11 以上）

1. 確認手機與電腦連線至**同一個區域網路**。
2. 進入手機「開發者選項」→「無線偵錯」，開啟功能。
3. 點選「使用配對碼配對裝置」，記下畫面上的：
   - 配對 IP 位址（例如 `192.168.1.50`）
   - **配對連接埠**（例如 `37123`，每次不同）
   - 6 位數配對碼
4. 在程式「裝置」頁右側「無線配對」卡片輸入 IP、配對連接埠與配對碼，按「執行無線配對」。
5. 配對成功後，回到「無線偵錯」畫面查看 **IP 位址與連線連接埠**（通常為 `5555` 或另一組號碼），在「無線連線」卡片輸入後按「連線無線裝置」。

> 配對連接埠與連線連接埠不同，請勿混用。

### 2.3 USB 一鍵轉無線

1. 先以 USB 連線並確認裝置狀態為「已連線」。
2. 確認手機與電腦在同一區域網路。
3. 於裝置列表點選「切換為無線連線」。
4. 程式會依序執行 `adb tcpip 5555`、查詢手機 Wi-Fi IP、`adb connect <IP>:5555`。
5. 成功後裝置會以無線方式重新出現在列表，並記錄於「常用無線裝置」供下次一鍵重連。

## 3. 開始同步

1. 啟動 `AndroidSync.exe`。
2. 於左側導覽選擇「裝置」。
3. 在「已連線裝置」列表確認手機狀態為「已連線」。
4. 按「開始同步畫面」，程式會自動：
   - 將 `scrcpy-server` 推送至手機（若已推送且未變更會跳過）。
   - 建立 ADB 連接埠轉發。
   - 啟動視訊、音訊與控制通道。
   - 初始化解碼器與 GPU 渲染管線。
5. 連線成功後會自動切換至「畫面同步」頁並顯示手機畫面。

## 4. 畫面操作

### 4.1 滑鼠

| 操作 | 手機行為 |
| --- | --- |
| 左鍵點擊 | 觸控點擊 |
| 左鍵長按 | 長按 |
| 左鍵拖曳 | 滑動 |
| 滾輪 | 上下捲動 |
| 右鍵 | 返回键 |
| 中鍵 | 主畫面鍵 |
| `Ctrl` + 左鍵拖曳 | 雙指縮放（Pinch） |

### 4.2 鍵盤

- 點擊同步畫面取得鍵盤焦點後即可直接輸入。
- 支援控制鍵、導覽鍵、功能鍵與組合鍵（例如 `Ctrl+C`、`Alt+Tab`、`Win` 鍵等，依 Android 映射）。
- ASCII 字元以 `INJECT_TEXT` 傳送；中文、日文、Emoji 等非 ASCII 文字會透過剪貼簿貼上至手機。
- `Ctrl+V` 會將電腦剪貼簿內容強制同步貼上至手機。

### 4.3 觸控螢幕與手寫筆

- 支援 Windows 觸控螢幕與手寫筆的多點觸控透傳。
- 同時觸控點數量依裝置與 Android 系統限制而定。

### 4.4 桌面快捷鍵

> 需先點擊同步畫面，讓鍵盤焦點位於畫面上。

| 快捷鍵 | 功能 |
| --- | --- |
| `Alt+O` | 切換手機息屏同步 |
| `Alt+S` | 擷取目前畫面（存 PNG + 複製剪貼簿） |
| `Alt+F` | 視窗貼合手機長寬比 |
| `Alt+T` | 切換視窗置頂 |
| `Alt+M` | 切換電腦端音訊靜音 |
| `Alt+R` | 旋轉手機畫面 |

## 6. 剪貼簿同步

- 於「設定」頁啟用「雙向剪貼簿同步」後，電腦與手機的剪貼簿會自動同步。
- 程式內建防迴圈機制，避免兩端互相覆寫。
- 中文 IME 注入時會暫時使用剪貼簿，程式會避免手機端回推覆寫你原本的電腦剪貼簿。
- 若只想手動同步，可於畫面按 `Ctrl+V` 將目前電腦剪貼簿貼上手機。

## 7. 拖放檔案與 APK

- 將檔案拖曳至同步畫面：
  - 一般檔案會推送至手機 `/sdcard/Download/`，並觸發媒體掃描。
  - `.apk` 檔案會執行 `adb install -r` 直接安裝。
- 傳輸期間底部會顯示狀態提示，完成後自動消失；錯誤訊息會停留較久。

---

## 8. 音訊

- 於「設定」頁開啟「同步播放手機音訊」。
- 預設使用 AAC 壓縮音訊以節省 Wi-Fi 頻寬；可切換為 RAW PCM。
- 播放優先使用 WASAPI 事件驅動低延遲模式，並自動跟隨 Windows 預設音訊裝置切換；失敗時退回 WaveOut。
- 裝置不支援音訊擷取（Android 11 以下或系統限制）時，會自動以純畫面模式繼續。

## 9. 設定頁

| 設定 | 說明 | 預設值 |
| --- | --- | --- |
| 顯示模式 | 跟隨系統／淺色／深色 | 跟隨系統 |
| 主題配色 | 經典藍／黃色護眼／森林綠／暮色紫／中性灰 | 經典藍 |
| ADB 路徑 | `adb.exe` 完整路徑（留空自動偵測） | 空 |
| scrcpy-server 路徑 | `scrcpy-server` 完整路徑（留空使用內附檔案） | 空 |
| scrcpy-server 版本 | 伺服器版本號，需與檔案相符 | `5.0.1` |
| 視訊編碼格式 | H.264／H.265（HEVC） | H.264 |
| 最大解析度 | 長邊上限；`0` 表示原始解析度 | `1080` |
| 位元率 | Mbps | `8` |
| 最大 FPS | 15–120 | `60` |
| 保持螢幕常亮 | 同步期間避免手機休眠 | 開啟 |
| 連線時關閉手機螢幕 | 啟動後立即息屏 | 關閉 |
| 雙向剪貼簿同步 | 電腦與手機剪貼簿同步 | 開啟 |
| 同步播放手機音訊 | 啟用音訊串流 | 開啟 |
| 壓縮音訊（AAC） | 關閉則使用 RAW PCM | 開啟 |
| 自動重連 | 串流中斷時自動重試 | 開啟 |
| 顯示效能 HUD | 預設顯示效能資訊 | 關閉 |

變更設定後請按「儲存」。外觀相關設定會即時套用並自動儲存。

## 10. 視窗與外觀

- 程式會記住視窗大小、位置與最大化狀態，下次啟動時自動還原。
- 還原前會檢查目前螢幕工作區域，避免視窗出現在螢幕外。
- 支援跟隨系統、淺色、深色三種顯示模式。
- 五款主題各自提供淺色與深色配色，切換即時生效，包含視窗標題列按鈕顏色。
- 同一時間僅允許執行一個實例；再次啟動會將既有視窗帶回前景。

---

## 11. 關閉程式

- 關閉視窗時，程式會先儲存視窗狀態，再停止同步、移除 ADB 連接埠轉發並結束 `scrcpy-server` 行程。
- 若有未完成的檔案傳輸，建議等待提示消失後再關閉。

---

## 12. 已知限制

- 需自行安裝 `adb.exe`；本專案未散布 Android Platform Tools。
- 螢幕錄影功能未納入規劃。
- 無線連線品質受區域網路與手機 Wi-Fi 效能影響；高延遲時可降低解析度、位元率或 FPS。
- 部分 Android 客製化系統可能限制音訊擷取或無線偵錯，功能會自動降級。
